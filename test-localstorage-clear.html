🧪 LocalStorage Clear Test

📋 テスト手順 - LocalStorage Clear機能の確認

【Phase 1: 設定変更】

  1. 列幅を任意にドラッグして変更する
  2. フィルターを複数設定する（例：給与、部署など）
  3. ソートを設定する（例：名前で昇順）
  4. メニューから文字サイズを「Large」に変更
  5. メニューからセルパディングを「Wide」に変更
  6. ページを再読み込みして設定が保存されていることを確認

【Phase 2: LocalStorage Clear実行】

  1. メニュー（⚙️）を開く
  2. 一番下の「LocalStorage クリア」をクリック
  3. 確認ダイアログで「削除する」をクリック
  4. 以下が発生することを確認：
    • ✅ 成功メッセージが表示される
    • ✅ 0.5秒後にページが自動リロードされる
    • ✅ リロード後、すべての設定がデフォルトに戻る
    • ✅ 列幅がデフォルトに戻る
    • ✅ フィルターがすべてクリアされる
    • ✅ ソートがクリアされる
    • ✅ 文字サイズが「Medium」に戻る
    • ✅ セルパディングが「Standard」に戻る
