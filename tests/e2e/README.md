# E2Eテスト実行ガイド

このディレクトリには、VanillaJS ExceLike TableのE2E（End-to-End）テストが含まれています。

## 概要

E2EテストはClaude CodeのMCP Playwright機能を使用して、実際のブラウザ環境でテーブル機能を検証します。

## 前提条件

1. ローカルサーバーが起動していること
   ```bash
   npm run dev
   # または
   npx http-server -p 8080 -c-1
   ```

2. Claude Code環境でMCP Playwrightが有効化されていること

## テスト実行手順

### Claude Codeでの実行

1. Claude Code CLIを起動
2. プロジェクトディレクトリに移動
3. ローカルサーバーを起動:
   ```bash
   npx http-server -p 8080 -c-1
   ```

4. Claude Codeで以下のように実行:
   ```
   tests/e2e/filter.test.mdのテストを実行してください
   ```

### 手動実行

各テストファイル（`.md`形式）には、以下の情報が記載されています：

1. **目的**: テストの目的と対象機能
2. **前提条件**: テスト実行前の必要な準備
3. **テスト手順**: ステップバイステップの手順
4. **期待結果**: 各ステップで期待される動作
5. **スクリーンショット**: テスト実行時のスクリーンショット保存場所

## トラブルシューティング

### ブラウザが起動しない

**問題**: Playwrightがブラウザを起動できない

**解決策**:
```bash
# Claude Codeで実行
ブラウザのインストールを確認してください
```

### ローカルサーバーに接続できない

**問題**: `http://localhost:8080` にアクセスできない

**解決策**:
1. ローカルサーバーが起動しているか確認
2. ポート8080が他のプロセスで使用されていないか確認
3. 別のポートを使用する場合は、テストファイル内のURLを変更

### タイムアウトエラー

**問題**: 要素が見つからずタイムアウトする

**解決策**:
1. ページが完全にロードされるまで待つ
2. セレクターが正しいか確認
3. 必要に応じて `browser_wait_for` を使用

## ベストプラクティス

1. **テストの独立性**: 各テストは他のテストに依存しないようにする
2. **クリーンアップ**: テスト後はフィルターやソートをクリア
3. **明示的な待機**: `browser_wait_for` を使用して要素の表示を待つ
4. **スクリーンショット**: 重要なステップでスクリーンショットを撮る
5. **エラーハンドリング**: 予期しないダイアログや警告を適切に処理
