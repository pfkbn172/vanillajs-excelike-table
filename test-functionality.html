🧪 ExceLikeTable 機能テストページ

埋め込み環境での問題を検証するための非埋め込み環境でのテスト

📋 テスト環境情報

  • 環境: 直接HTMLファイル（非埋め込み）
  • 目的: 報告された問題が埋め込み環境固有かを確認
  • ライブラリ: ローカルdistファイルを使用
テスト1: 列幅調整機能
列のヘッダ境界線上でカーソルが左右矢印（col-resize）に変わり、ドラッグで列幅を調整できることを確認します。

📝 テスト手順:

  1. 列ヘッダ（「名前」「部署」等）の右端境界線にマウスを移動
  2. カーソルが左右矢印（↔）に変わることを確認
  3. 境界線上でダブルクリックして自動調整を確認
  4. ドラッグして列幅を手動調整できることを確認
テスト2: 数値フィルタダイアログ
数値列（給与）のフィルタボタンを押したときに、範囲スライダー付きのフィルタ設定画面が正常に開くことを確認します。

📝 テスト手順:

  1. 「給与」列のヘッダにあるフィルタアイコン（🔽）をクリック
  2. フィルタダイアログが開き、範囲スライダーが表示されることを確認
  3. 最小値・最大値の入力フィールドが機能することを確認
  4. 個別値のチェックボックスが表示されることを確認
  5. 適用ボタンでフィルタが実行されることを確認
テスト3: 日付フィルタ展開表示
日付列のフィルタで、選択済みの日付を含む年が正しく展開表示（▼）されることを確認します。特に年内に1件しか日付がない場合の動作を検証します。

📝 テスト手順:

  1. 「入社日」列のフィルタアイコン（🔽）をクリック
  2. 日付フィルタダイアログが開くことを確認
  3. 2024年の日付を1つ選択して適用
  4. 再度フィルタを開き、2024年の展開アイコンが▼（展開状態）になっていることを確認
  5. 2023年など他の年の展開アイコンが▶（折りたたみ状態）になっていることを確認
