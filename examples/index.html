🚀 VanillaJS ExceLike Table - Full Featured Demo with Settings Persistence

Features Demonstrated:

  • Filtering: Text search, numeric range sliders, date hierarchy
  • Sorting: Click column headers to sort ascending/descending
  • Column Pinning: Pin columns to left side with sticky positioning
  • Column Visibility: Show/hide columns via settings menu
  • Pagination: Navigate through large datasets with configurable page sizes
  • Responsive Design: Works on desktop and mobile devices
  • Column Resizing: Drag column borders to resize widths
  • 🆕 Settings Persistence: All settings automatically saved to LocalStorage and restored on page reload

💾 Settings Persistence Feature:

  • Auto-Save: All changes (filters, sorting, column widths, etc.) are automatically saved to LocalStorage
  • Auto-Restore: Settings are automatically restored when you reload the page
  • Persisted Settings: Column widths, visibility, pinning, filters, sort state, font size, cell padding, page size
  • Manual Controls: Use "Save Settings Now" to force save, or "Clear Saved Settings" to reset to defaults
  • Test It: Make changes, refresh the page, and see your configuration restored!
