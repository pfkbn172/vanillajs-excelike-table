ExceLikeTable v2.4.0 確認ページ

公開前の確認用です。表はすべて dist/excelike-table.browser.js（今回ビルドしたもの）で動いています。

1. データを渡すだけ（列の指定なし）

  • 列の指定を書いていないのに、データのキーごとに列ができている
  • 見出しの文字をクリックすると並べ替わる（昇順 → 降順 → 解除）
  • 漏斗アイコンで絞り込み、下でページ送り、⚙️ でメニュー（アイコンが空の四角になっていない）
  • ブラウザの開発者ツールのコンソールに何も出ていない
new ExceLikeTable('#t1', { data: staff });

2. 列の指定・日本語表示・CSV 書き出し

  • メニューや絞り込みが日本語（英語が混ざっていない）
  • 年収は「¥」付きの3桁区切り、状態は色分けされている
  • ⚙️ →「CSVで書き出し」で、絞り込み・並べ替え後の全行が CSV になる。Excel で開いても文字化けせず、マイナスの数値も数値のまま
  • ⚙️ →「条件付き書式」でルール（例：年収 < 5000000 なら背景色）を作ると色が付く
